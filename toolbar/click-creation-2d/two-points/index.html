Two Points

After clicking two points on a 2D graph, a menu appears with these operations.

How It Works​

  +---------------------------+
  |          2D Graph          |
  |                            |
  |     x  <-- 1st click       |
  |              x  <-- 2nd    |
  |                            |
  |   +------------------+     |
  |   | Line             |     |
  |   | Vector           |     |
  |   | Measure          |     |
  |   | Arc              |     |
  |   | Conics > Circle  |     |
  |   | Conics > Ellipse |     |
  |   +------------------+     |
  +---------------------------+

Line​

OperationWhat It Creates
Lineinfinite line through two points
Segmentline segment between points
Rayray from P1 through P2

Vector​

OperationWhat It Creates
Two Pointsvector from P1 to P2

Measure​

OperationWhat It Creates
Measuredistance marker between two points

Point​

OperationWhat It Creates
CartesianCreates individual point expression for each collected point

Arc​

OperationWhat It Creates
Arcelliptical arc between two points

Circle​

OperationWhat It Creates
Center + Pointcircle with center at P1, passing through P2
Diametercircle with diameter P1-P2

Ellipse​

OperationWhat It Creates
Fociellipse with P1 and P2 as foci
