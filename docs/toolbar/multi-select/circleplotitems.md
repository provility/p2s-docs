# Circle + Plot

Operations available when you select a **circle** and a **plot** together.

## How to Use

```
  1. Click on a circle object to select it
  2. Hold Shift and click on a plot object
  3. Right-click to open the context menu
  4. Choose an operation from the menu
```

## Available Operations

| Operation | Description |
|-----------|-------------|
| **Intersect** | Handler for circle+plot selection |

## Expression Details

**Find intersection points of a circle and a plot**

```
intersect(G, C, P, n)
```
