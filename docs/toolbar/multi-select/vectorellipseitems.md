# Ellipse + Vector

Operations available when you select a **ellipse** and a **vector** together.

## How to Use

```
  1. Click on a ellipse object to select it
  2. Hold Shift and click on a vector object
  3. Right-click to open the context menu
  4. Choose an operation from the menu
```

## Available Operations

| Operation | Description |
|-----------|-------------|
| **Intersect** | Handler for ellipse+vector selection |

## Expression Details

**Find intersection points of a vector and an ellipse**

```
intersect(G, V, E, n)
```
