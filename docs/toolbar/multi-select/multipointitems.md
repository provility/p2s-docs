# Multi-Point

Operations available when you select **multi-point** objects.

## How to Use

```
  1. Select multiple multi-point objects (Shift + click)
  2. Right-click to open the context menu
  3. Choose an operation from the menu
```

## Available Operations

| Operation | Description |
|-----------|-------------|
| **Polygon** | Handler for 3+ points selection |
| **Polyline** | Create a polygon from selected points |

## Expression Details

**Create a polygon from selected points**

```
polygon(G, P1, P2, P3, ...)
```

**Create a polyline from selected points**

```
polyline(G, P1, P2, P3, ...)
```
