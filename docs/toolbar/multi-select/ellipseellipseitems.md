# Ellipse + Ellipse

Operations available when you select a **ellipse** and a **ellipse** together.

## How to Use

```
  1. Click on a ellipse object to select it
  2. Hold Shift and click on a ellipse object
  3. Right-click to open the context menu
  4. Choose an operation from the menu
```

## Available Operations

| Operation | Description |
|-----------|-------------|
| **Intersect** | Handler for two-ellipse selection |

## Expression Details

**Find intersection points of two ellipses**

```
intersect(G, E1, E2, n)
```
