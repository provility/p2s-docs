# Circle + Vector

Operations available when you select a **circle** and a **vector** together.

## How to Use

```
  1. Click on a circle object to select it
  2. Hold Shift and click on a vector object
  3. Right-click to open the context menu
  4. Choose an operation from the menu
```

## Available Operations

| Operation | Description |
|-----------|-------------|
| **Intersect** | Handler for circle+vector selection |

## Expression Details

**Find intersection points of a vector and a circle**

```
intersect(G, V, C, n)
```
