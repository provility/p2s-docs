# Line + Plot

Operations available when you select a **line** and a **plot** together.

## How to Use

```
  1. Click on a line object to select it
  2. Hold Shift and click on a plot object
  3. Right-click to open the context menu
  4. Choose an operation from the menu
```

## Available Operations

| Operation | Description |
|-----------|-------------|
| **Intersect** | Handler for line+plot selection |

## Expression Details

**Find intersection points of a line and a plot**

```
intersect(G, L, P, n)
```
