# Line + Vector

Operations available when you select a **line** and a **vector** together.

## How to Use

```
  1. Click on a line object to select it
  2. Hold Shift and click on a vector object
  3. Right-click to open the context menu
  4. Choose an operation from the menu
```

## Available Operations

| Operation | Description |
|-----------|-------------|
| **Intersect** | Handler for line+vector selection |

## Expression Details

**Find intersection point of a line and a vector**

```
intersect(G, L, V, n)
```
