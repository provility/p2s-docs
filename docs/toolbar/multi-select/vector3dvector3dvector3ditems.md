# Vector 3D + Vector 3D + Vector 3D

Operations available when you select a **vector3d** and a **vector3d** together.

## How to Use

```
  1. Click on a vector3d object to select it
  2. Hold Shift and click on a vector3d object
  3. Right-click to open the context menu
  4. Choose an operation from the menu
```

## Available Operations

| Operation | Description |
|-----------|-------------|
| **Box Product (Parallelepiped)** | Handler for three 3D vector selection |

## Expression Details

**Create a parallelepiped (box product) from three vectors**

```
boxprod(G, V1, V2, V3)
```
