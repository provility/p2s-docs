# Line 3D + Line 3D

Operations available when you select a **line3d** and a **line3d** together.

## How to Use

```
  1. Click on a line3d object to select it
  2. Hold Shift and click on a line3d object
  3. Right-click to open the context menu
  4. Choose an operation from the menu
```

## Available Operations

| Operation | Description |
|-----------|-------------|
| **Angle** | Handler for two 3D line selection |
| **Intersect** | Create angle between two lines |

## Expression Details

**Create angle between two lines**

```
angle3d(G, L1, L2)
```

**Find intersection point of two lines**

```
intersect3d(G, L1, L2)
```
