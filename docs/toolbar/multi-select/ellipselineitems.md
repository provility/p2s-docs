# Ellipse + Line

Operations available when you select a **ellipse** and a **line** together.

## How to Use

```
  1. Click on a ellipse object to select it
  2. Hold Shift and click on a line object
  3. Right-click to open the context menu
  4. Choose an operation from the menu
```

## Available Operations

| Operation | Description |
|-----------|-------------|
| **Intersect** | Handler for ellipse+line selection |

## Expression Details

**Find intersection points of a line and an ellipse**

```
intersect(G, L, E, n)
```
