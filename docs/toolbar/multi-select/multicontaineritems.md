# Multi-Container

Operations available when you select **multi-container** objects.

## How to Use

```
  1. Select multiple multi-container objects (Shift + click)
  2. Right-click to open the context menu
  3. Choose an operation from the menu
```

## Available Operations

| Operation | Description |
|-----------|-------------|
| **Size** | Container types that support size() expression |

## Expression Details

**Container types that support size() expression**

```
Handler for multi-container selection (2+ containers)
```

**Generate size() expression**

```
size(G, M, widthRatio, heightRatio)
```
