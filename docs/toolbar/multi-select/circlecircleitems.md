# Circle + Circle

Operations available when you select a **circle** and a **circle** together.

## How to Use

```
  1. Click on a circle object to select it
  2. Hold Shift and click on a circle object
  3. Right-click to open the context menu
  4. Choose an operation from the menu
```

## Available Operations

| Operation | Description |
|-----------|-------------|
| **Intersect** | Handler for two-circle selection |

## Expression Details

**Find intersection points of two circles**

```
intersect(G, C1, C2, n)
```
