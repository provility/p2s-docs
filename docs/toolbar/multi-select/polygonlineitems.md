# Line + Polygon

Operations available when you select a **line** and a **polygon** together.

## How to Use

```
  1. Click on a line object to select it
  2. Hold Shift and click on a polygon object
  3. Right-click to open the context menu
  4. Choose an operation from the menu
```

## Available Operations

| Operation | Description |
|-----------|-------------|
| **Intersect** | Handler for line+polygon selection |

## Expression Details

**Find intersection points of a line and a polygon**

```
intersect(G, L, Poly, n)
```
