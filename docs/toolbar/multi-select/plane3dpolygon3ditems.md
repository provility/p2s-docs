# Plane 3D + Polygon 3D

Operations available when you select a **plane3d** and a **polygon3d** together.

## How to Use

```
  1. Click on a plane3d object to select it
  2. Hold Shift and click on a polygon3d object
  3. Right-click to open the context menu
  4. Choose an operation from the menu
```

## Available Operations

| Operation | Description |
|-----------|-------------|
| **Reflect** | Handler for 3D plane + 3D polygon selection |

## Expression Details

**Reflect polygon across plane**

```
reflect3d(plane, polygon)
```
