# Write + Write

Operations available when you select a **write** and a **write** together.

## How to Use

```
  1. Click on a write object to select it
  2. Hold Shift and click on a write object
  3. Right-click to open the context menu
  4. Choose an operation from the menu
```

## Available Operations

| Operation | Description |
|-----------|-------------|
| **Convert to Flow** | WriteWriteItems - Handler for multiple plain write-output selections |

## Expression Details

**WriteWriteItems - Handler for multiple plain write-output selections**

```
- All are "plain" writes (not mflow, meq, mseq, or mlist)
```
