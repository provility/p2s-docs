# Two Points

After clicking **two points** on a 2D graph, a menu appears with these operations.

## How It Works

```
  +---------------------------+
  |          2D Graph          |
  |                            |
  |     x  <-- 1st click       |
  |              x  <-- 2nd    |
  |                            |
  |   +------------------+     |
  |   | Line             |     |
  |   | Vector           |     |
  |   | Measure          |     |
  |   | Arc              |     |
  |   | Conics > Circle  |     |
  |   | Conics > Ellipse |     |
  |   +------------------+     |
  +---------------------------+
```

## Line

| Operation | What It Creates |
|-----------|----------------|
| **Line** | infinite line through two points |
| **Segment** | line segment between points |
| **Ray** | ray from P1 through P2 |

## Vector

| Operation | What It Creates |
|-----------|----------------|
| **Two Points** | vector from P1 to P2 |

## Measure

| Operation | What It Creates |
|-----------|----------------|
| **Measure** | distance marker between two points |

## Point

| Operation | What It Creates |
|-----------|----------------|
| **Cartesian** | Creates individual point expression for each collected point |

## Arc

| Operation | What It Creates |
|-----------|----------------|
| **Arc** | elliptical arc between two points |

## Circle

| Operation | What It Creates |
|-----------|----------------|
| **Center + Point** | circle with center at P1, passing through P2 |
| **Diameter** | circle with diameter P1-P2 |

## Ellipse

| Operation | What It Creates |
|-----------|----------------|
| **Foci** | ellipse with P1 and P2 as foci |
