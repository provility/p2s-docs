# Four or More Points

After clicking **four or more points** on a 2D graph, a menu appears with these operations.

## How It Works

```
  +---------------------------+
  |          2D Graph          |
  |   x       x                |
  |       x       x            |
  |   x               x        |
  |                            |
  |   +------------------+     |
  |   | Point            |     |
  |   | Polygon          |     |
  |   +------------------+     |
  +---------------------------+
```

## Point

| Operation | What It Creates |
|-----------|----------------|
| **Cartesian** | Creates individual point expression for each collected point |

## Polygon

| Operation | What It Creates |
|-----------|----------------|
| **Polygon** | polygon from clicked vertices |
| **Polyline** | open path through points |
