# Three Points

After clicking **three points** on a 2D graph, a menu appears with these operations.

## How It Works

```
  +---------------------------+
  |          2D Graph          |
  |     x  <-- 1st             |
  |          x  <-- 2nd        |
  |     x  <-- 3rd             |
  |                            |
  |   +------------------+     |
  |   | Angle            |     |
  |   | Polygon          |     |
  |   | Conics > Circle  |     |
  |   +------------------+     |
  +---------------------------+
```

## Angle

| Operation | What It Creates |
|-----------|----------------|
| **Three Points** | angle at vertex |
| **Interior** | interior angle (≤180°) |
| **Reflex** | reflex angle (>180°) |
| **Right Angle** | right angle marker |

## Point

| Operation | What It Creates |
|-----------|----------------|
| **Cartesian** | Creates individual point expression for each collected point |

## Polygon

| Operation | What It Creates |
|-----------|----------------|
| **Triangle** | triangle from three vertices |
| **From Points** | polygon from clicked vertices |
| **Polyline** | open path through points |

## Circle

| Operation | What It Creates |
|-----------|----------------|
| **Three Points** | circumcircle through three points |
