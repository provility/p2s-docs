# One Point

After clicking **one point** on a 2D graph, a menu appears with these operations.

## How It Works

```
  +---------------------------+
  |          2D Graph          |
  |                            |
  |        x  <-- click        |
  |                            |
  |   +------------------+     |
  |   | Point            |     |
  |   | Line             |     |
  |   | Vector           |     |
  |   | Circle           |     |
  |   | Arc              |     |
  |   | Polygon          |     |
  |   | Triangle         |     |
  |   +------------------+     |
  +---------------------------+
```

## Point

| Operation | What It Creates |
|-----------|----------------|
| **Cartesian** | point at clicked coordinates |
| **Polar** | point at polar coordinates |

## Line

| Operation | What It Creates |
|-----------|----------------|
| **Vertical** | vertical line through point |
| **Horizontal** | horizontal line through point |
| **Polar** | line through point at angle from origin |

## Vector

| Operation | What It Creates |
|-----------|----------------|
| **Position** | position vector from origin to point |
| **Polar** | vector from origin at angle |

## Circle

| Operation | What It Creates |
|-----------|----------------|
| **Center + Radius** | circle with given radius |

## Arc

| Operation | What It Creates |
|-----------|----------------|
| **Center + Angle** | arc from center point |

## Polygon

| Operation | What It Creates |
|-----------|----------------|
| **Square** | square from point |
| **Rectangle** | rectangle from point |

## Triangle

| Operation | What It Creates |
|-----------|----------------|
| **Right △** | right triangle (hypotenuse computed) |
| **SAS** | 2 sides + included angle |
| **ASA** | 2 angles + included side |
| **AAS** | 2 angles + opposite side |
