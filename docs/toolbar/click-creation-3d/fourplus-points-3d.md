# Four+ Points (3D)

After clicking **four or more points** on a 3D graph, a menu appears with these operations.

## How It Works

```
  +---------------------------+
  |          3D Graph          |
  |     x   /  x     /         |
  |      / x    x   /          |
  |     /--------/             |
  |                            |
  |   +------------------+     |
  |   | Point            |     |
  |   | Polygon          |     |
  |   +------------------+     |
  +---------------------------+
```

## Point

| Operation | What It Creates |
|-----------|----------------|
| **Multipoint** | Creates individual points for each clicked location |

## Polygon

| Operation | What It Creates |
|-----------|----------------|
| **Polygon** | polygon from n points |
