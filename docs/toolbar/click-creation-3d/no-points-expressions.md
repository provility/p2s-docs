# No Points (Expressions)

Without clicking any points on a 3D graph, you can create expression-based objects like surfaces and curves.

## How It Works

```
  +---------------------------+
  |          3D Graph          |
  |       /        /           |
  |      /  click /            |
  |     /--------/             |
  |                            |
  |   +------------------+     |
  |   | Plot (surface)   |     |
  |   | Region           |     |
  |   | Revolution        |     |
  |   | Disk Stack        |     |
  |   +------------------+     |
  +---------------------------+
```

## Plot

| Operation | What It Creates |
|-----------|----------------|
| **Parametric Curve** | parametric curve in 3D |
| **Explicit Surface** | explicit surface |
| **Parametric Surface** | parametric surface |

## Region

| Operation | What It Creates |
|-----------|----------------|
| **From Curves** | bounded region between curves |

## Revolution

| Operation | What It Creates |
|-----------|----------------|
| **From Region** | solid of revolution |

## Disk Stack

| Operation | What It Creates |
|-----------|----------------|
| **From Region** | stack of disks for volume visualization |
