# Three Points (3D)

After clicking **three points** on a 3D graph, a menu appears with these operations.

## How It Works

```
  +---------------------------+
  |          3D Graph          |
  |       /  x     /           |
  |      / x    x /            |
  |     /--------/             |
  |                            |
  |   +------------------+     |
  |   | Point            |     |
  |   | Polygon          |     |
  |   | Plane            |     |
  |   +------------------+     |
  +---------------------------+
```

## Point

| Operation | What It Creates |
|-----------|----------------|
| **Multipoint** | Creates individual points for each clicked location |

## Polygon

| Operation | What It Creates |
|-----------|----------------|
| **Triangle** | triangle from 3 points |

## Plane

| Operation | What It Creates |
|-----------|----------------|
| **Through 3 Points** | plane through 3 points |
