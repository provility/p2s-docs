# One Point (3D)

After clicking **one point** on a 3D graph, a menu appears with these operations.

## How It Works

```
  +---------------------------+
  |          3D Graph          |
  |       /        /           |
  |      /  x     /            |
  |     /--------/             |
  |                            |
  |   +------------------+     |
  |   | Point            |     |
  |   | Vector           |     |
  |   | Sphere           |     |
  |   +------------------+     |
  +---------------------------+
```

## Point

| Operation | What It Creates |
|-----------|----------------|
| **Cartesian** | 3D point at clicked coordinates |

## Vector

| Operation | What It Creates |
|-----------|----------------|
| **Position** | position vector from origin |

## Sphere

| Operation | What It Creates |
|-----------|----------------|
| **Center + Radius** | sphere with given radius |
